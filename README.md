# Mech Gauge（Webアプリ）

機械加工・検査の現場向け計算ツール。はめあい公差・ねじ寸法・三角関数／テーパを、大きなUIで。完全オフライン動作（ブラウザ内で計算完結）。

**公開URL:** https://mecha-sekkei.github.io/Mech-Gauge/

- `index.html` — 紹介ページ
- `app.html` — 計算機本体（ブラウザ版）
- `privacy_policy.html` — プライバシーポリシー

## GitHub Pages 設定
Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / Folder: **/ (root)** → Save

iOSアプリのソースは別の非公開リポジトリで管理しています。

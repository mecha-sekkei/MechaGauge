# Mech Gauge（Webアプリ）

機械加工・検査の現場向け計算ツール。**インストール不要、ブラウザだけで動きます。**
計算はすべてブラウザ内で完結し、入力した数値が外部に送信されることはありません。

**公開URL:** https://mecha-sekkei.github.io/Mech-Gauge/

## 収録している6つの機能

| 機能 | 内容 |
|---|---|
| はめあい公差 | 穴A〜ZC・軸a〜zc・IT1〜18。すきま／中間／しまりを判定（JIS B 0401 / ISO 286-1） |
| ねじ諸元 | メートル並目 M0.8〜M48・細目・ウイット・管用。有効径／谷径／二面幅／六角穴レンチ、タップ下穴はひっかかり率で調整 |
| 三角関数・テーパ | 2つ入力すれば残りを自動計算。テーパ比・勾配の換算 |
| ボルト・軸の強度 | 有効断面積・締付軸力・締付トルク（JIS B 1051 / B 1082 / B 1083）、軸のねじり＋曲げ合成と必要径の逆算 |
| 切削条件 | フライス／ドリル／旋盤。回転数・送り・除去率・所要動力・加工時間・理論粗さ |
| 梁のたわみ・強度 | 支持条件×荷重の8ケース。型鋼（H形鋼・溝形鋼・山形鋼・鋼管）対応。たわみ基準と応力で合否判定 |

画面右の「早見表」からタップ下穴表・材料表・公式集をいつでも参照でき、計算履歴は端末内に自動保存されます。

## 開発の方針（2026-08-02〜）

**現在はWeb版に一本化して開発しています。** iOSアプリ版は、Web版のテスト完了と
広告掲載の許可が揃うまで保留です。`app.html` はこのリポジトリのものが正本で、

## 免責

表示する数値は JIS・ISO 規格に基づく**参考値**です。強度・構造の計算結果は設計の最終根拠にはせず、
必ず規格原典と有資格者の確認に基づいて判断してください。

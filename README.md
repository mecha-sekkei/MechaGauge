# Mecha Gauge（Webアプリ）

機械加工・検査の現場向け計算ツール。**インストール不要、ブラウザだけで動きます。**
計算はすべてブラウザ内で完結し、入力した数値が外部に送信されることはありません。

**公開URL:** https://mecha-sekkei.github.io/MechaGauge/

## 2つの版

| 版 | ファイル | 内容 |
|---|---|---|
| 広告あり | [`app_adsense.html`](app_adsense.html) | Google AdSense の広告を表示します（自動生成物） |
| 広告なし | [`app_noads.html`](app_noads.html) | 広告を出しません。**こちらが正本です** |

> 広告あり版は非公開リポジトリの `build_variants.sh` が `app_noads.html` から自動生成しています。
> **手で編集しないでください**（内容がずれます）。修正は `app_noads.html` に対して行い、再生成します。

## 収録している8つの機能

| 機能 | 内容 |
|---|---|
| はめあい公差 | 穴A〜ZC・軸a〜zc・IT1〜18。すきま／中間／しまりを判定（JIS B 0401 / ISO 286-1） |
| ねじ諸元 | メートル並目 M0.8〜M48・細目 M1×0.2〜・ミニチュア S0.3〜（JIS外）・ウイット・管用。有効径／谷径／二面幅／六角穴レンチ、タップ下穴はひっかかり率で調整 |
| 三角関数・テーパ | 2つ入力すれば残りを自動計算。テーパ比・勾配の換算 |
| ボルト・軸の強度 | 有効断面積・締付軸力・締付トルク（JIS B 1051 / B 1082 / B 1083）、軸のねじり＋曲げ合成と必要径の逆算 |
| 切削条件 | フライス／ドリル／旋盤。回転数・送り・除去率・所要動力・加工時間・理論粗さ |
| 梁のたわみ・強度 | 支持条件×荷重の8ケース。型鋼（H形鋼・溝形鋼・山形鋼・鋼管）対応。強軸／弱軸を切り替えて比較でき、たわみ基準と応力で合否判定 |
| タクトタイム計算 | 台形加減速。時間／最高速度／加減速度のどれでも逆算でき、必要推力も算出。アクチュエータ選定に |
| 重量計算 | 板・丸棒・パイプ・角材・角パイプ・中空ボックス・アングル・六角棒・型鋼。**101種類の材料**を密度付きで収録し、比重を調べるだけでも使えます |

- 各機能に**寸法の図解**が付いています（JIS Z 8317 準拠の寸法線。折りたたみ可）
- 計算結果は**テキストでコピー**、または**A4比率のPNG画像**として保存できます（白背景・印刷向け）
- 画面右の「早見表」からタップ下穴表・材料密度表・公式集をいつでも参照でき、計算履歴は端末内に自動保存されます
- 材料は「ジュラコン」「ニューライト」「テフロン」などの**商品名でも検索**できます

## 開発の方針（2026-08-02〜）

**現在はWeb版に一本化して開発しています。** iOSアプリ版は、Web版のテスト完了と
広告掲載の許可が揃うまで保留です。`app_noads.html` がこのリポジトリの正本で、
iOS側（非公開リポジトリ）は保留時点で止まっています。

計算式は複数の資料および独立検算と照合しています（検証記録は非公開リポジトリの `verification.md`）。

## GitHub Pages 設定

Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / Folder: **/ (root)** → Save

## 免責

表示する数値は JIS・ISO 規格に基づく**参考値**です。強度・構造の計算結果は設計の最終根拠にはせず、
必ず規格原典と有資格者の確認に基づいて判断してください。

材料名に併記しているメーカー商品名（ジュラコン、ニューライト、テフロン等）は各社の登録商標です。
材質の目安として併記しているもので、その製品の値を保証するものではありません。
